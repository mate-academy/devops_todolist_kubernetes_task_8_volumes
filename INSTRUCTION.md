# Инструкции по валидации деплоя

## 1. Проверка, что приложение запущено

Выполните команду:
```bash
kubectl get pods -n todoapp
```
Убедитесь, что статус пода — `Running`.

## 2. Проверка, что данные из ConfigMap смонтированы как файлы в правильном порядке

Выполните команду для получения имени пода:
```bash
kubectl get pods -n todoapp
```
Затем зайдите в под:
```bash
kubectl exec -it <имя-пода> -n todoapp -- /bin/sh
```
Проверьте наличие файлов, смонтированных из ConfigMap:
```bash
ls /path/to/configmap/mount
cat /path/to/configmap/mount/<имя_файла>
```
Убедитесь, что файлы расположены и содержат данные в нужном порядке.

## 3. Проверка, что данные из Secret смонтированы как файл

Внутри пода выполните:
```bash
ls /path/to/secret/mount
cat /path/to/secret/mount/<имя_файла>
```
Убедитесь, что файл существует и содержит ожидаемые секретные данные.

---
Замените `/path/to/configmap/mount` и `/path/to/secret/mount` на реальные пути, указанные в вашем Deployment-манифесте.
